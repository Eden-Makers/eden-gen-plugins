# Eden Gen for Cursor

Generate images, video and audio from Cursor with 200+ models in one Eden Gen account: Seedance, Kling, Veo, Nano Banana, GPT Image, Seedream, ElevenLabs, MiniMax and more.

- Connects to the remote MCP server `https://edengen.ai/mcp` with OAuth. No API key in Cursor.
- Every run is estimated first; runs above your confirmation threshold ask before they start.
- Each connection is limited to one project and the monthly cap you approve on the consent screen.
- Failed takes are refunded automatically.

Includes the `eden-gen` skill: how to pick a model, price a run, use first frames and references, and upload local files.

Docs: https://edengen.ai/docs/agents · Support: support@edengen.ai · Privacy: https://edengen.ai/privacy
