# Claude directory

`SUBMISSION.md` is the text to paste into the Claude connector directory. The Claude Code plugin and skill already live at `plugins/claude` in this repository, so this folder does not add a second copy.

## Submission steps

1. Read `SUBMISSION.md` and paste each labelled block into https://claude.ai/directory/manage.
2. Connect `https://edengen.ai/mcp` in the portal and finish OAuth.
3. Confirm the synced tools match the table in `SUBMISSION.md`.
4. Run the test prompts in Claude before marking the test step done.

## Review requirements

Remote MCP, OAuth, tool annotations, privacy policy, support contact, documentation, a test account, and at least three working prompts. Details and the paste text are in `SUBMISSION.md`.
